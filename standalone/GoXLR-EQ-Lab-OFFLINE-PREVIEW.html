Only the coefficient data format is implemented. Flashing or live DSP write controls are disabled until the physical headphone DAC, processing budget, stream isolation and recovery are verified.

Never upload the .gxeq file to any firmware updater. It is a 988-byte research data bank, not a GoXLR firmware image.
